🍪 Snack Manager

Scan snacks, record expiry dates, and export to Excel.

1. Excel database

Connecting to your GitHub Excel database…

The app automatically reads Snack_Manager_Starter.xlsx from this GitHub Pages repository and merges it with records saved on this device. Use Export to download an updated Excel copy.

Manual Excel import (optional)

2. Scan barcode

If a barcode is not in your saved list, Snack Manager can try the free Open Food Facts database. Product matches are not guaranteed, especially for some Japanese snacks.

3. Add stock

The barcode usually does not contain the expiration date. Enter the date printed on the package.

4. Expiration reminders

Snack Manager checks each batch for two reminders: approximately 1 month (30 days) and 10 days before expiration.

Notifications are not enabled yet. You can still see reminders here when you open the app.

5. Buyer screen (kids)

Full-screen mode for the kids: big photos, 1 / 2 / 3-point buttons, points always visible and a DONE button that passes the phone to the next kid. Tip: after opening it, add this page to your Home Screen so it opens straight into the buyer screen.

Each new day starts again at kid 1.

7. Shopping list

Tap “Min stock” on a snack in the inventory to set a minimum. Snacks that drop below it appear here.

8. Sync between devices

Keeps your inventory, points and photos identical on every phone or computer by saving a file (snack_data.json) in your GitHub repository. If the repository is public, anyone with the link could read that file.

Not connected.

Set up / change
  1. On GitHub: Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: “Only select repositories” → pick this app’s repository.
  3. Permissions → Repository permissions → Contents: Read and write. Generate and copy the token.
  4. Paste it below on each device you use. The token stays on that device only.
